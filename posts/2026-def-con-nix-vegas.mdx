## 2026 DEF CON 34 Nix Vegas

I fulfilled a childhood dream of mine - attend DEF CON! Not only that,
I'm very excited to say that I gave two presentations on Nix while there!

I'm also very grateful that [exa.ai](https://exa.ai) allowed me to present
what I've been working on this summer + provided support for me to attend
the conference with my team.

### August 7th, 2026 - Let's Talk About Caching - Tarball Cache Presentation

My first presentation was a lightning talk about an s3-backed microservice that
I wrote that acts as a proxy or pull-through cache for Git forge tarballs. It
supports GitHub, GitLab, Sourcehut, and Codeberg, and the design is very
simple.

[Link to slides](https://ethancedwards.com/latex/presentations/2026-def-con-nix-vegas/tarball-cache/slides.pdf)

[Link to tarball cache source code](https://github.com/ethancedwards8/tarball-cache)

[Link to slides source](https://github.com/ethancedwards8/ethancedwards.com/tree/master/public/latex/presentations/2026-def-con-nix-vegas/tarball-cache)


### August 8th, 2026 - Infra as DAG Presentation

My second presentation was a longer, 45 minute talk about how using Nix to
model infrastructure and deployments as DAGs (Directed Acyclic Graph)s. There
isn't any handout code, but the presentation details a few different designs
and how I thought about creating the ideal Nix setup for a web scale monorepo.

[Link to slides](https://ethancedwards.com/latex/presentations/2026-def-con-nix-vegas/infra-as-dag/slides.pdf)

[Link to slides source](https://github.com/ethancedwards8/ethancedwards.com/tree/master/public/latex/presentations/2026-def-con-nix-vegas/infra-as-dag)
